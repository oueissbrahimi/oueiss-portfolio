# Portfolio — Brahimi Ahcen Oueiss

React 18 · Vite · Tailwind CSS · lucide-react. Ready for Vercel.

```bash
npm install
npm run dev      # local
npm run build    # production build
```

## Edit your content
Everything lives in `src/data/site.js` (profile, skills, project).
- `PROFILE.linkedin` — paste your LinkedIn URL; the button appears in Contact and Footer.
- `PROJECT.repo` — repository link for ESICodeHub.

## Deploy
Push to GitHub and import the repo on Vercel (framework preset: Vite). `vercel.json` is already configured.
